# Tin học 11 – Bài 6: Lưu trữ và chia sẻ tệp tin trên Internet

Website gồm 5 phần: Khởi động, Hình thành kiến thức, Luyện tập, Vận dụng, Củng cố & nộp bài.

## Chạy thử
Mở `index.html` bằng trình duyệt; không cần cài thêm thư viện.

## Đưa lên GitHub Pages
1. Tạo repository, ví dụ `tin-hoc-11-bai-6`.
2. Upload `index.html` và `README.md` vào thư mục gốc của nhánh `main`.
3. Mở **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, nhấn **Save**.
5. Website thường có địa chỉ `https://TEN-TAI-KHOAN.github.io/tin-hoc-11-bai-6/`.

## Nộp bài
Nút nộp bài tạo file CSV có thể mở bằng Microsoft Excel, gồm họ tên, lớp, điểm, đáp án và phần vận dụng. GitHub Pages là hosting tĩnh nên không thể tự ghi thẳng vào file Excel tập trung của giáo viên. Học sinh cần tải CSV về và nộp theo hướng dẫn. Muốn thu bài tự động vào một bảng chung, cần tích hợp Google Apps Script/Google Sheets hoặc backend.

## Chỉnh sửa
Mã nguồn nằm trong `index.html`. Câu hỏi có thể chỉnh trong các mảng `warm`, `perms` và `quiz`.
